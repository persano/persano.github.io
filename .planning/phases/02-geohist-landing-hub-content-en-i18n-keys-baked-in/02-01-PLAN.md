## i18n Key Contract (locked for Phase 3 — per D-20/D-21)

- Text nodes: `data-i18n="geohist.<section>.<element>"` (landing), `guide.<section>.<element>` (guide, plan 02-02), `hub.<n>` (hub, plan 02-02).
- Attributes: `data-i18n-attr="attr:key"` — comma-separated for multiple attributes, e.g. `data-i18n-attr="alt:geohist.hero.icon.alt"`. Elements whose ONLY translatable content is attributes additionally carry `data-i18n-attr-only`.
- Keys are ASCII dotted identifiers; EN copy is UTF-8.
- `<title>` gets `data-i18n` (harmless now, I18N-04 in Phase 3 consumes it). Meta description stays EN-only this phase — flagged for Phase 3.
