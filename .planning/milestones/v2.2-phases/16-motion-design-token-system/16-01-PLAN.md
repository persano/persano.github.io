# Plan 16-01: Motion & Design Token System

## Goal
Implement foundational design tokens and mobile-native properties in `css/base.css`: elevation tiers with ambient shadows and inset highlights, spring easing curves, optical display tracking, translucent border variables, dynamic viewport height (`100dvh`), tap highlight elimination, and reduced-motion kill-switch.

## Tasks

### Task 1: Define Elevation, Motion, and Typography Tokens in :root (TOK-01, TOK-02, TOK-03)
- In `:root` in `css/base.css`:
  - Add elevation tokens:
    - `--elevation-low`: subtle elevation for compact chips/badges
    - `--elevation-mid`: standard elevation for cards (`box-shadow: 0 4px 16px -2px rgba(0, 0, 0, 0.45), 0 1px 4px rgba(0, 0, 0, 0.3), inset 0 1px 0 rgba(240, 230, 210, 0.08)`)
    - `--elevation-high`: prominent elevation for modals/popovers
  - Add motion tokens:
    - `--ease-spring-snappy: cubic-bezier(0.16, 1, 0.3, 1)`
    - `--ease-spring-gentle: cubic-bezier(0.25, 1, 0.5, 1)`
    - `--dur-micro: 120ms`
    - `--dur-interaction: 220ms`
    - `--dur-expand: 320ms`
  - Typography tracking & translucent borders:
    - Update `h1`, `h2`, `h3` with tighter optical letter-spacing (`letter-spacing: -0.015em`, `letter-spacing: -0.02em` for h1).
    - Introduce `--border-subtle: 1px solid rgba(201, 184, 154, 0.16)` and `--border-card: 1px solid rgba(201, 184, 154, 0.22)`.
    - Apply `--elevation-mid` and `--border-card` to card elements (`.card`, `.feature-card`, `.fact-pill`, etc.) replacing flat borders with illuminated cards.

### Task 2: Implement Mobile-Native Defaults and Safe-Area Insets (MOB-01, MOB-02)
- In `body`, `main`, and interactive elements in `css/base.css`:
  - Set `min-height: 100vh; min-height: 100dvh;` on `body`.
  - Add `padding-left: max(1.25rem, env(safe-area-inset-left)); padding-right: max(1.25rem, env(safe-area-inset-right)); padding-bottom: max(2rem, env(safe-area-inset-bottom));` on `main` and container elements to prevent notch/home-bar collision.
  - Set `-webkit-tap-highlight-color: transparent;` on `*, *::before, *::after`.
  - Set `touch-action: manipulation;` on `a, button, input, select, textarea, summary, [role="button"]` to prevent 300ms double-tap zoom delay on mobile browsers.

### Task 3: Site-Wide Prefers-Reduced-Motion Override (MOB-03)
- Add comprehensive reduced motion query at the end of `css/base.css`:
  - `@media (prefers-reduced-motion: reduce)`:
    - Force `animation-duration: 0.01ms !important; animation-iteration-count: 1 !important; transition-duration: 0.01ms !important; scroll-behavior: auto !important;`
    - Reset transforms where motion is reduced.

## Verification
- Run `npm run validate` to ensure zero CSS/HTML/i18n regressions.
- Verify tokens match design requirements TOK-01..03, MOB-01..03.
