# Plan 18-01: Screenshot Showcase & Lightbox

## Goal
Upgrade the screenshot gallery on `index.html` with mobile scroll-snap reel, pagination dots, accessible full-screen modal lightbox, and robust progressive enhancement.

## Tasks

### Task 1: Mobile Scroll-Snap Reel and Pagination Indicators in CSS (GAL-01, GAL-03)
- In `css/base.css`:
  - Upgrade `.gallery-grid` for mobile (`@media (max-width: 640px)`):
    - `display: flex; overflow-x: auto; scroll-snap-type: x mandatory; gap: 1rem; padding-bottom: 0.75rem; -webkit-overflow-scrolling: touch; scrollbar-width: none;`
    - `.gallery-tile`: `flex: 0 0 70vw; max-width: 16rem; scroll-snap-align: center; cursor: pointer;`
  - Define pagination indicator container `.gallery-dots` and `.gallery-dot` (visually hidden if JS not active or styled cleanly).
  - Progressive enhancement: When JS is absent, screenshots are fully scrollable and legible via standard CSS scroll-snap with native touch physics.

### Task 2: Interactive Lightbox Modal Script and CSS (GAL-02, GAL-03)
- Create `js/gallery.js`:
  - Self-contained, zero-global IIFE.
  - Setup click listener on `.gallery-tile` to open full-screen lightbox modal showing high-res WebP image.
  - Setup pagination dots reflecting current scroll index.
  - Keyboard accessibility: Trap ESC to close, Left/Right arrow keys for navigation.
  - Backdrop click or close button dismisses modal.
  - Focus returns to opening tile upon close.
- In `css/base.css`:
  - Add lightbox styles: `.lightbox-overlay`, `.lightbox-dialog`, `.lightbox-close`, `.lightbox-img`.
  - Animate entrance with `--ease-spring-snappy` and `--dur-interaction`.
- In `index.html`:
  - Add `<script defer src="js/gallery.js"></script>`.
  - Add lightbox `<dialog>` or overlay markup container.

## Verification
- Run `npm run validate` (HTML validate, links check, i18n checks).
- Verify GAL-01, GAL-02, GAL-03 requirements pass.
